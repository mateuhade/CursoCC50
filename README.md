## O que é este curso?


Este é um curso com a duração de cerca de *3 meses* feito pela **Universidade de Harvard** e traduzido pela **Fundação Estudar**. Ele aborda os conceitos fundamentais de programação como estruturas
de dados, sintaxes gerais e algoritmos. O curso utiliza em grande parte a linguagem C para ensinar os conceitos básicos como loops, vetores, matrizes, métodos, árvores, grafos, gerenciamento de memória, 
condições, tipos de dados, recursão, interação com arquivos, bibliotecas, etc. Após isso o curso começa a apresentar novas linguagens e frameworks, avançando para a utilização de Python com o objetivo de 
realizar atividades mais complexas com um esforço menor e uma sintaxe mais simplificada. E por último, o professor *David J. Malan* apresenta a interação entre diversas linguagens diferentes ao desafiar 
os alunos a desenvolverem sites e aplicações Web, utilizando Flask/Python, SQL, JavaScript, HTML e CSS. <br>
Este é um curso extremamente denso, apresentando muitos conceitos relevantes para todas áreas e aplicações da programação e engenharia de software. Ele contém cerca de 30 atividades contendo graus variados 
de dificuldade, a mais infame sendo Tideman durante a seção de "3Algorithms" e Homepage na seção "9Flask", além do projeto final do curso.

# Seções e atividades


## 0. Scratch


<img src="https://crystalpng.com/wp-content/uploads/2025/04/scratch-cat-png.png" alt="Scratch's cat character" width="100"> <br>

A seção de Scratch do curso aborda os conceitos mais iniciais e básicos de programação como input, output, loops e condições como o computador "pensa" e como nós devemos interagir com ele. A parte de 
programação desta seção introduz os alunos a estes conceitos utilizando a linguagem de programação para crianças, Scratch, e plantando algumas sementes para introduzir outros conceitos futuramente como 
arvores binárias de busca. 

Esta seção possui apenas uma atividade que requer que o usuário utilize algumas funções específicas como loops e saída de dados para realizar um projeto simples à escolha do aluno. 
[Aqui está o que eu desenvolvi.](https://scratch.mit.edu/projects/1305971291/embed)


## 1. C 


<img src="https://upload.wikimedia.org/wikipedia/commons/thumb/d/d8/C_Language_Logo.svg/960px-C_Language_Logo.svg.png" alt="C Programming Language Logo" width="100"> 

A seção de C do curso introduz os alunos à primeira linguagem real de programação que eles irão utilizar, C. Aqui nós começamos a introduzir conceitos mais concretos das linguagens de programação como 
funções, tipos de dados, entrada de dados, saída de dados, variáveis, IDEs, comandos do terminal, compiladores, bibliotecas e a própria sintaxe de linguagens orientadas à objetos de nível intermediário. <br>
As atividades nesta seção são voltadas principalmente à utilização de matemática e números na programação, além da utilização lógica predominante de condições e loops para a validação de valores como 
[cartões de crédito.](https://github.com/mateuhade/CursoCC50/blob/main/1C/exercises/credit.c)


## 2. Arrays


<img src="https://arquivos.respondeai.com.br/seo-mirror/theory/2023/76a022cf-b10c-48d4-bef0-618fbe3e8ccb.webp" alt="Vetor de 3 índices e matriz 3x2" height="100"> 

A seção Arrays do curso apresenta a estrutura mais básica de armazenamento de conjuntos de dados: arrays/vetores. Além disso ela também começa à abstrair e revelar como funcionam elementos que utilizavamos 
sem nem sequer entender, como o compilador, return 0;, int main(void), argc, argv, constantes e até mesmo strings que não existem como um tipo de dados nativo de C, mas como um arranjo de chars. <br>
As atividades desta seção refletem a utilização de caracteres ASCII, [cifras](https://github.com/mateuhade/CursoCC50/blob/main/2Arrays/exercises/caesar.c) e tratamentos de erros e exceções causadas 
pelo usuário.


## 3. Algorithms


<img src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRIT_MPBNhmgM-W2-lBO5nsiQDFn9xgF36uY2hEa3y4_AsXlo6HTmenOaqY&s=10" alt="Visualizador de algoritmo de ordenação" height="100">

A seção de Algorithms apresenta aos alunos algoritmos de ordenação, structs, recursão e algoritmos de pesquisa. 

Durante estas atividades nós somos desafiados a utilizar o que foi apresentado para simular diversos métodos de eleição, é também nesta seção que o exercício [tideman](https://github.com/mateuhade/CursoCC50/blob/main/3Algorithms/exercises/tideman.c), 
infame por sua dificuldade é dado.


## 4. Memory


<img src="https://m.media-amazon.com/images/I/71vhrbllH3L.jpg" alt="Uma relíquia de preço imensurável do passado tornada inacessível por uma praga que até hoje tenta destruir a humanidade" height="100">

Esta seção apresenta pointers, gerenciamento de memória, tipos de memória, valores de lixo, endereços de memória, RGB e a interação de códigos com arquivos persistentes. Além disso ela também abstrai e 
explica mais alguns conceitos como scanf, cores e comparação de strings. 

As atividades desta seção são voltadas a utilidades mais comuns para o público geral, como a aplicação de [filtros em imagens](https://github.com/mateuhade/CursoCC50/blob/main/4Memory/exercises/filter-more/filter.c) 
por meio de matemática aplicada em cada byte dela.


## 5. Data Structures


<img src="https://cdn.programiz.com/sites/tutorial2program/files/perfect-binary-tree_0.png" alt="Estrutura de árvore binária de busca" height="100">

Aqui nós somos apresentados as estruturas de dados mais utilizadas, como árvores, grafos, pilhas, filas, listas vinculadas, tries, nódulos, raízes, quais estruturas são mais adequadas para quais situações, 
e como as notações de Big O são utilizadas neste contexto.
Estas atividades são mais voltadas à utilização de pointers como nódulos para a implementação de [estruturas de dados diversas](https://github.com/mateuhade/CursoCC50/blob/main/5DataStructures/exercises/inheritance.c)


## 6. Python


<img src="https://upload.wikimedia.org/wikipedia/commons/thumb/c/c3/Python-logo-notext.svg/3840px-Python-logo-notext.svg.png" alt="Logo da linguagem de programação python" height="100">

Nesta seção o professor nos apresenta a uma nova linguagem de programação de alto nível, Python. Esta aula é extremamente densa, mostrando: 

- Novos tipos de dados como dicionários, sets, tuplas, etc; 
- Como Python roda com um interpretador ao contrário de um compilador;
- Como podemos utilizar python para interagir com bancos de dados, utilizando CSVs nesta seção;
- Como Python pode ser utilizado para interagir com objetos reais;
- O poder que Python tem para resolver problemas complexos com muito menos esforço apenas utilizando bibliotecas e funções nativas.

As atividades desta seção consistem em realizar alguns [exercícios anteriores](https://github.com/mateuhade/CursoCC50/blob/main/6Python/exercises/credit.py), mas desta vez em Python, para nos acostumar 
com a nova sintaxe. Além disso, também somos desafiados a interagir com bancos de dados para [realizar cálculos](https://github.com/mateuhade/CursoCC50/blob/main/6Python/exercises/worldCup/tournament.py) 
e executar funções específicas.


## 7. SQL


<img src="https://upload.wikimedia.org/wikipedia/commons/8/87/Sql_data_base_with_logo.png" alt="Logo da linguagem de consulta SQL" height="100">

Aqui nós aprendemos como utilizar a linguagem de consulta de bancos de dados SQL, por meio da ferramenta SQLite3. Nesta aula vemos as principais funções da linguagem, como tipos de dados, tabelas, 
interações entre tabelas, operações, índices, operadores, comandos, chaves, cláusulas, injeções de SQL, como utilizar Python para automatizar o processo de entrada e saída de dados e funções gerais.

Por conta do quão específica é essa linguagem, as atividades desta seção são relativamente mais simples. Ditto isso, uma das minhas atividades favoritas do curso está [aqui](https://github.com/mateuhade/CursoCC50/blob/main/7SQL/exercises/fiftyville/log.sql), 
nela nós precisamos utilizar consultas em SQL para interagir com um banco de dados extensivo e utilizar o conteúdo adquirido para resolver um mistério.


## 8. Web


<img src="https://www.freepnglogos.com/uploads/javascript-png/logo-html5-js-css3-png-transparent-logo-4.png" alt="Logos das linguagens de programação e marcação HTML, CSS e JavaScript" height="100">

Nesta seção nos é apresentado como utilizar as linguagens de marcação HTML e CSS, bem como a linguagem de programação JavaScript para desenvolver o front-end de um site. Aqui nós aprendemos como criar um 
site utilizando: 
- Tags e elementos dentro de HTML para definir o que o site irá conter;
- IDs, classes e tags em CSS para definir como o site será visualmente;
- Código de programação para fazer o site ser responsivo ao usuário.

Esta seção contém a minha atividade favorita, nela nós devemos fazer um site contendo no mínimo 4 páginas apresentando quem somos, servindo como uma forma de biografia pessoal. Para ver como o meu site 
ficou, baixe o diretório [Homepage](https://github.com/mateuhade/CursoCC50/tree/main/8Web/exercises/Homepage), instale python, abra o terminal e mova-se até o caminho do diretório que baixou, ex: 
`cd C:/Documentos/Homepage`, ainda no terminal instale Flask com `pip install Flask`, e por fim rode `Flask run` no terminal e aperte ctrl+click no link que surgir para abrir o site.


## 9. Flask


<img src="https://raw.githubusercontent.com/tandpfun/skill-icons/main/icons/Flask-Dark.svg" alt="Logo do Framework de Python, Flask" height="100">

Nesta última seção, nós utilizamos o que aprendemos nas últimas 3 seções para criar sites com um back-end real. Aqui nós vemos como utilizar o framework Flask para criar rotas, utilizar templates, obter 
dados do usuário, impedir ataques por meio de HTML, interpretar códigos de status, interagir com bancos de dados e utilizar cookies de usuário.

As atividades desta seção envolvem essencialmente implementar funções back-end e front-end para criar um [site](https://github.com/mateuhade/CursoCC50/tree/main/9Flask/exercises/Finance) que se assemelha 
a um site que você poderia ver navegando pela internet.
